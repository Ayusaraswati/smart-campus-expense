# Smart Campus Expense & Financial Tracker

Dashboard web interaktif berbasis studi kasus nyata kehidupan sehari-hari mahasiswa untuk mencatat, mengelola, dan memvisualisasikan data pengeluaran secara *real-time*.

## 🛠️ Fitur Utama Aplikasi
- **Pencatatan Keuangan Real-Time:** Form interaktif untuk memasukkan nama keperluan, memilih kategori (Akademik, Organisasi, Kebutuhan, Lainnya), dan nominal anggaran.
- **Statistik & Ringkasan Otomatis:** Kartu ringkasan untuk memantau total pengeluaran, jumlah item transaksi, dan kategori pengeluaran terbesar.
- **Grafik Batang Dinamis (*Bar Chart*):** Visualisasi proporsi persentase pengeluaran yang otomatis memperbarui diri secara instan.
- **Filter & Manajemen Tabel:** Fitur untuk menyaring catatan berdasarkan kategori tertentu serta menghapus data transaksi dengan mudah.
